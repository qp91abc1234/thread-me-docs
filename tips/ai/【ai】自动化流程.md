# AI 自动化流程

## 一、核心概念

- `Context`：项目背景（必写） + 概念约束（按需补充，避免歧义）。
- `Rules`：行为约束（按需补充），例如内容生成位置、写作方式、输出格式等。
- `Skill`：
  - 功能说明类 Skill（例如组件 Skill）。
  - 可复用流程类 Skill：
    - 需求分析：理解需求并生成 Spec。
    - 可复用功能：例如新建页面。
    - 代码验收 Skill。
- `MCP`：大模型执行过程可调用的工具集合。
- `Spec`：`Spec = Context + Rules + Tests`。

## 二、自动化流程

1. 执行「需求分析 Skill」  
   生成 Spec（包含 Tests）。

2. 人工审核 Spec  
   - 有问题：修改 Spec（循环）。  
   - 没问题：进入开发。

3. 执行「开发（实现）」  
   按 `Spec + Context + Rules` 编写代码。

4. 执行「验收 Skill」  
   使用 MCP 打开页面、操作并对比结果。

5. 判断结果  
   - ❌ 不通过：反馈问题，回到步骤 3 修复（循环）。  
   - ✅ 通过：进入下一步。

6. 人工最终审核  
   确认代码质量、结构与边界场景。

7. （可选）提交代码（MCP）
