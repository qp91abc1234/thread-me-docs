## 面向对象三大核心

### 封装

把数据和行为绑定在一起，隐藏内部细节，只暴露必要的方法

### 继承

子类复用父类的成员（非 private 的字段和方法），并可以扩展或修改

### 多态

> 父类类型的引用变量可以指向子类对象，并且在运行时根据实际对象的类型来决定调用哪个方法（动态绑定），而非根据引用变量的类型

编译看左边，运行看右边：引用类型决定能调用哪些方法，实际对象类型决定方法如何执行

```java
Animal animal = new Dog();

animal.shout();

if (animal instanceof Dog) {
    Dog dog = (Dog) animal;
}
```

## 类

```java
public class Person {
    String name;

    public void eat() {
        System.out.println("吃饭");
    }
}

public class User extends Person {
    public User() {
        System.out.println("创建对象");
    }

    public User(String name, int age) {
        this.name = name;
    }

    public void sayHello() {
        System.out.println(this.name);
    }

    @Override
    public void eat() {
        super.eat();
        System.out.println("用户吃饭");
    }
}

User user = new User();
user.sayHello();
```

## 类名 & Class 对象

- 类名
  - ex. UserController
  - 用于创建对象、类型转换、编译期检查（编译时）
- Class 对象
  - ex. UserController.class
  - 存储模板信息，根据它创建实例对象
  - 用于操作元数据、反射（运行时）

```java
Java 中的类对象：
┌─────────────┐    编译      ┌─────────────┐    加载      ┌──────────────────┐
│  class Dog  │ ──────────→  │  Dog.class  │ ──────────→  │  Class 对象       │
│  { bark() } │              │  (字节码)   │              │  - 类名: "Dog"    │
└─────────────┘              └─────────────┘              │  - 方法: [bark]   │
                                                          │  - 构造器: ...    │
                                                          └──────────────────┘
                                                                ↓
                                                          通过这个对象可以：
                                                          - 查看方法列表
                                                          - 创建新实例
                                                          - 动态调用方法
                                                          - 读取注解
```

## 访问修饰符

```java

│  │  ├─ 同包可见
```

## 抽象类

不能 new，太抽象，因为现实里你不会创建一个 “动物”

抽象类不一定有抽象方法，但有抽象方法一定是抽象类

抽象方法：子类是具体类，必须重写

```java
public abstract class Animal {
    public abstract void run();
}
```

## 接口

纯规范：用来约束能做什么，默认就是抽象的

```java
public interface Animal {
    // 常量：默认 public static final
    int MAX_AMOUNT = 10000;

    // 默认 public abstract
    void shout();

    // 默认方法：有默认实现，子类可以重写也可以不重写
    default void beforePay() {
        System.out.println("支付前准备");
    }

    // 静态方法：通过接口名直接调用
    static void validateAmount(double amount) {
        if (amount <= 0) throw new IllegalArgumentException("金额必须大于0");
    }
}

public class Dog implements Animal {
    @Override
    public void shout() {
        System.out.println("汪汪汪");
    }
}
```

函数式接口 & Lambda

1. 函数式接口：只有一个抽象方法的接口
2. 匿名内部类：创建一个没有类名（或父类）的接口实现类，并直接实例化出对象的底层机制
3. Lambda：用来简化通过函数式接口创建匿名内部类对象的语法糖

```java
// 函数式接口：只有一个抽象方法的接口
@FunctionalInterface
interface StringProcessor {
    String process(String s);
}

// 使用匿名内部类创建对象
StringProcessor p1 = new StringProcessor() {
    @Override
    public String process(String s) {
        return s.toUpperCase();
    }
};

// 使用 Lambda 简化（等价于上面）
StringProcessor p2 = s -> s.toUpperCase();
```
