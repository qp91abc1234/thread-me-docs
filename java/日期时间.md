## 概念

时间戳

- 时间戳的起点是 UTC（1970-01-01 00:00:00 UTC）
- 时间戳没有时区属性

## 时间对象

```java
LocalDate today = LocalDate.now(); // 日期（年-月-日）
LocalTime nowTime = LocalTime.now(); // 时间（时:分:秒.纳秒）
LocalDateTime now = LocalDateTime.now(); // 日期+时间
Instant instant = Instant.now(); // UTC时间戳

LocalDate date = LocalDate.of(2026, 6, 25);
LocalTime time = LocalTime.of(14, 30, 15);
LocalDateTime dt = LocalDateTime.of(2026, 6, 25, 14, 30, 15);
```

## 字符串日期转换

```java
LocalDateTime now = LocalDateTime.now(); // 日期+时间

// 定义格式化器（线程安全，可复用）
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

// 日期转字符串
String str = now.format(formatter);

// 字符串转日期
LocalDateTime dt = LocalDateTime.parse("2026-06-25 14:30:15", formatter);
```

## 时间差

```java
// 日期差（年月日）
Period period = Period.between(startDate, endDate);
int years = period.getYears();
int months = period.getMonths();
int days = period.getDays();

// 时间差（时分秒毫秒）
Duration duration = Duration.between(startTime, endTime);
long seconds = duration.getSeconds();
long millis = duration.toMillis();
```

## 获取年月日时分秒

```java
int year = now.getYear();
int month = now.getMonthValue();      // 1-12
int day = now.getDayOfMonth();
int hour = now.getHour();
int minute = now.getMinute();
int second = now.getSecond();
DayOfWeek dow = now.getDayOfWeek();   // 枚举
```

## 时间戳（毫秒）与 LocalDateTime 互转

```java
// 毫秒时间戳 → LocalDateTime
long millis = System.currentTimeMillis();
LocalDateTime dt = Instant.ofEpochMilli(millis)
        .atZone(ZoneId.systemDefault())
        .toLocalDateTime();

// LocalDateTime → 毫秒时间戳
long millis2 = now.atZone(ZoneId.systemDefault()).toInstant().toEpochMilli();
```
