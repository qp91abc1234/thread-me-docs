## 哈希

Hash 算法：一种“计算编号”的算法，生成 hashCode

hashCode 不能唯一标识被存储的数据，根据数学上的抽屉原理（鸽巢原理），既然数据是无限的，而哈希值是有限的，那么必然存在无数个不同的对象拥有完全相同的 hashCode

Hash 表（Hash Table）本质：数组 + hash算法：通过 hash 算法计算元素应该放在数组的哪个位置

### HashMap 本质

数组 + 链表 + 红黑树（链表和红黑树是为了解决冲突后的性能问题）

```java
static class Node<K, V> {
    final int hash; // hash值
    final K key;    // key
    V value;        // value
    Node<K, V> next; // 下一个节点
}

table[0]
table[1]
table[2] -> Node -> Node
table[3]
table[4] -> Node -> Node -> Node
```

### HashMap 存储流程

1. 计算 hash `key.hashCode()`
2. 定位到数组位置（bucket） `(hash & (length - 1))`
3. 判断 bucket 是否为空
   - 空，直接存入：`table[index] = Node`
   - 不空，比较 hash + equals，用于确认 key 是否重复
     - （比较 hash 是性能优化，可快速筛选不用到 equals 比较）
     - key 相同，覆盖；key 不同，挂到链表后面

### HashMap 获取流程

1. 计算 hash `key.hashCode()`
2. 定位到数组位置（bucket） `(hash & (length - 1))`
3. 比较 hash + equals，找到对应节点后返回 value

### HashSet

内部是只有 key 没有 value 的 HashMap

### 重写 hashCode & equals

如果对象要作为 HashMap key 或者放进 HashSet，需要重写 equals 和 hashCode

因为默认会用地址算 hash，Set 的去重，Map 的查找覆盖都可能失效

```java
class User {
    Long id;
    String name;

    public User(Long id, String name) {
        this.id = id;
        this.name = name;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;

        if (!(o instanceof User)) return false;

        User user = (User) o;

        return Objects.equals(id, user.id);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id);
    }
}
```
