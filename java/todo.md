## java

### 数据结构

```java
第1周：数组 + 链表
      → 每天手写一次链表反转、快慢指针判环

第2周：栈 + 队列
      → 实现循环队列、用栈实现队列、单调栈模板

第3周：哈希表 + 二叉树
      → 理解哈希冲突解决、手写三种遍历（递归+迭代）

第4周：BST + AVL
      → 重点攻克 BST 删除、AVL 四种旋转

第5周：堆
      → 手写堆（上浮/下沉）、堆排序、Top K

第6周：红黑树 + 图
      → 红黑树理解 5 条规则和插入修复，图掌握 DFS/BFS + Dijkstra
```
