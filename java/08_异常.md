## 异常分类

```java
Throwable
 ├── Error
 └── Exception
       ├── RuntimeException  ← 非受检异常
       └── 其他 Exception    ← 受检异常
```

- Error：JVM 级严重错误，基本不能恢复，ex.OutOfMemoryError, StackOverflowError
- 受检异常：编译器要求必须显式处理的异常
- 非受检异常：继承自 RuntimeException 的异常，编译器不会检查是否处理

## 异常抛出

```java
if (str == null) {
    throw new IllegalArgumentException("参数不能为空");
}
```

## 自定义异常

```java
// 推荐继承 RuntimeException（非受检）
public class BusinessException extends RuntimeException {
    private String code;

    public BusinessException(String message) {
        super(message);
    }

    public BusinessException(String code, String message) {
        super(message);
        this.code = code;
    }
}
```

## 异常处理

```java
// 自动关闭实现了 AutoCloseable 的资源（如流、连接）
try (FileInputStream fis = new FileInputStream("a.txt");
     BufferedReader br = new BufferedReader(new InputStreamReader(fis))) {
    // 使用资源
} catch (IOException e) {
    e.printStackTrace();
}
// 无需 finally，自动关闭
```

```java
try {
    // 可能抛出 IOException 或 SQLException 的代码，抛出的异常不能有继承关系
} catch (IOException | SQLException e) {
    // 统一的异常处理逻辑
    logger.error("IO或数据库异常", e);
}
```

throws：主要针对受检异常，不处理时交给调用者处理

```java
public void readFile() throws IOException {
    // 不处理，交给调用者
}
```
