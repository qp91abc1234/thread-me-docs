## 基础

注解本质是特殊的接口，编译时生成元数据，运行时反射读取

### 使用注解

```java
// 使用 value 属性（可省略 value= 直接写值）
@GetMapping("/user")
public String getUser() { return "user"; }

// 使用多个路径
@GetMapping(value = {"/user", "/profile"})
public String getProfile() { return "profile"; }
```

### 定义注解

```java
@Target(ElementType.METHOD)      // 元注解：限定该注解只能用在方法上
@Retention(RetentionPolicy.RUNTIME) // 元注解：保留到运行时（可通过反射读取）
public @interface GetMapping {   // 使用 @interface 关键字定义注解
    String[] value() default {}; // 注解属性：类型 属性名() default 默认值; （括号是一定有的）
}
```

### ElementType

| 取值              | 适用目标                       | 说明                       |
| ----------------- | ------------------------------ | -------------------------- |
| `TYPE`            | 类、接口（包括注解类型）、枚举 | 用在类、接口、枚举、注解上 |
| `FIELD`           | 字段（包括枚举常量）           | 用在成员变量、枚举常量上   |
| `METHOD`          | 方法                           | 用在方法上                 |
| `PARAMETER`       | 方法参数                       | 用在方法的形式参数上       |
| `CONSTRUCTOR`     | 构造方法                       | 用在构造方法上             |
| `ANNOTATION_TYPE` | 注解类型                       | 用在注解定义上（元注解）   |

### RetentionPolicy

| 取值      | 保留策略           | 说明                                                             |
| --------- | ------------------ | ---------------------------------------------------------------- |
| `SOURCE`  | 源码级别           | 注解只保留在源码中，编译时会被丢弃，不会出现在 `.class` 文件中   |
| `CLASS`   | 字节码级别（默认） | 注解会保留在 `.class` 文件中，但运行时不可读（JVM 加载时会丢弃） |
| `RUNTIME` | 运行时级别         | 注解会保留在 `.class` 文件中，且运行时可通过反射读取             |

## 反射获取注解

```java
import java.lang.reflect.Method;

public class AnnotationReflectionDemo {

    // 1. 定义注解（就是你的例子）
    @Target(ElementType.METHOD)
    @Retention(RetentionPolicy.RUNTIME)
    public @interface GetMapping {
        String[] value() default {};
    }

    // 2. 使用注解
    public class UserController {
        @GetMapping("/user")
        public String getUser() {
            return "user info";
        }

        @GetMapping({"/profile", "/info"})
        public String getProfile() {
            return "profile info";
        }

        @GetMapping  // 使用默认值（空数组）
        public String getDefault() {
            return "default";
        }
    }

    // 3. 运行时反射读取注解
    public static void main(String[] args) throws Exception {
        // 获取 UserController 的所有方法
        Method[] methods = UserController.class.getDeclaredMethods();

        for (Method method : methods) {
            System.out.println("\n=== 方法: " + method.getName() + " ===");

            // ⭐ 关键方法：判断方法上是否标注了 @GetMapping
            if (method.isAnnotationPresent(GetMapping.class)) { // 接口本质也是特殊形式的类，所以有类对象
                // ⭐ 关键方法：获取注解实例
                GetMapping getMapping = method.getAnnotation(GetMapping.class);

                // ⭐ 读取注解属性值
                String[] paths = getMapping.value();

                if (paths.length == 0) {
                    System.out.println("路径: 使用默认值（空数组）");
                } else {
                    System.out.println("路径: " + String.join(", ", paths));
                }
            }
        }
    }
}
```
