## 基本使用

```java
public enum StatusEnum {
    ENABLE, DISABLE  // 全大写，多个单词用下划线
}

// 使用
StatusEnum status = StatusEnum.ENABLE;
```

枚举（enum）本质上是类，在编译时会被编译器转换成一个继承自 java.lang.Enum 的最终类

枚举常量（如 ENABLE、DISABLE）本质上是单例静态变量（static final 变量），所以可以用 == 判断相等，因为地址唯一

## 内置方法

```java
// 获取枚举名称（字符串）
StatusEnum.ENABLE.name();          // "ENABLE"

// 获取序号（从0开始，谨慎使用，顺序变动会有影响）
StatusEnum.ENABLE.ordinal();       // 0

// 根据字符串转枚举（常用于前端传参）
StatusEnum.valueOf("ENABLE");      // 返回 ENABLE

// 遍历所有枚举值
for (StatusEnum s : StatusEnum.values()) {
    System.out.println(s);
}
```

## 扩展

```java
public enum OrderStatusEnum {
    WAIT_PAY(0, "待支付"),
    PAID(1, "已支付"),
    CANCEL(2, "已取消");

    private final Integer code;
    private final String desc;

    // 构造器必须是私有的（默认就是private，可以省略）
    OrderStatusEnum(Integer code, String desc) {
        this.code = code;
        this.desc = desc;
    }

    // Getter（只提供getter，不提供setter，保证不可变）
    public Integer getCode() { return code; }
    public String getDesc() { return desc; }

    // ========== 高频工具方法 ==========

    // 根据code获取枚举（接口传code时必用）
    public static OrderStatusEnum fromCode(Integer code) {
        for (OrderStatusEnum status : values()) {
            if (status.getCode().equals(code)) {
                return status;
            }
        }
        throw new IllegalArgumentException("未知状态码: " + code);
        // 或者 return null; 视业务而定
    }

    // 根据code获取描述（前端展示常用）
    public static String getDescByCode(Integer code) {
        OrderStatusEnum status = fromCode(code);
        return status == null ? "未知状态" : status.getDesc();
    }
}
```

### 枚举与接口

```java
// 定义行为接口
public interface PayStrategy {
    String pay(Map<String, Object> params);
}

// 枚举实现策略
public enum PayChannelEnum implements PayStrategy {
    ALIPAY {
        @Override
        public String pay(Map<String, Object> params) {
            return "调用支付宝支付接口";
        }
    },
    WECHAT {
        @Override
        public String pay(Map<String, Object> params) {
            return "调用微信支付接口";
        }
    },
    BANK_CARD {
        @Override
        public String pay(Map<String, Object> params) {
            return "调用银行卡支付接口";
        }
    };

    // 还可以定义公共方法
    public String getChannelName() {
        return this.name();
    }
}

// 使用：直接获取枚举并调用方法
PayChannelEnum channel = PayChannelEnum.valueOf("ALIPAY");
String result = channel.pay(params);  // 不需要if/else判断
```

### 枚举与单例

线程安全、防止反序列化破解、代码极简（推荐使用）

```java
public enum Singleton {
    INSTANCE;

    public void doSomething() {
        // 业务方法
    }
}

// 调用
Singleton.INSTANCE.doSomething();
```
