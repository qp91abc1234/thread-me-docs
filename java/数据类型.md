```java
Java 数据类型
│
├─ 基本类型 (8种)
│  ├─ 整数型: byte, short, int, long
│  ├─ 浮点型: float, double
│  ├─ 字符型: char
│  └─ 布尔型: boolean
│
└─ 引用类型
   │
   ├─ 数组类型 (Array)
   │  ├─ 一维数组: int[], String[], Object[]
   │  └─ 多维数组: int[][], String[][][]
   │
   └─ 类类型 (Class)
      │
      ├─ 包装类 (Wrapper Classes)
      │  ├─ Number 的子类: Byte, Short, Integer, Long, Float, Double
      │  ├─ Character
      │  └─ Boolean
      │
      ├─ 字符串类: String, StringBuilder, StringBuffer
      │
      ├─ 集合框架 (Collections Framework)
      │  │
      │  ├─ Collection 接口
      │  │  ├─ List 接口
      │  │  │  ├─ ArrayList
      │  │  │  ├─ LinkedList (也实现 Queue)
      │  │  │  ├─ Vector
      │  │  │  └─ Stack (Vector的子类)
      │  │  │
      │  │  ├─ Set 接口
      │  │  │  ├─ HashSet
      │  │  │  │  └─ LinkedHashSet
      │  │  │  └─ TreeSet
      │  │  │
      │  │  └─ Queue 接口
      │  │     ├─ LinkedList
      │  │     ├─ PriorityQueue
      │  │     └─ ArrayDeque
      │  │
      │  └─ Map 接口 (独立分支，不属于 Collection)
      │     ├─ HashMap
      │     │  └─ LinkedHashMap
      │     ├─ TreeMap
      │     ├─ Hashtable
      │     └─ ConcurrentHashMap
      │
      └─ 其他类: Object, Date, Calendar, 自定义类等
```

> Collection 和 Map 都是"包装类型的容器"，不能直接存放基本类型
